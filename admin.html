How to Publish Changes (1-Minute Guide for Non-Technical Members)

Because this website is static and hosted on GitHub Pages, publishing an update is as easy as editing a text document on GitHub.com without installing any software!

Method A: Directly on GitHub.com (Recommended for Fast Edits)

  1. Use this tool to make your edits and click "Copy to Clipboard" above.
  2. Navigate to your GitHub repository in your web browser (e.g. github.com/yorksunburysar/website).
  3. Click on the data/ folder, then select the file (news.json, team.json, or faq.json).
  4. Click the Pencil icon (Edit this file) in the top right.
  5. Select all and Paste your copied content.
  6. Click the green "Commit changes" button. Your website updates automatically in about 30 seconds!

Method B: Drag & Drop Downloaded File

  1. Click "Download [file].json" above to save the file to your Downloads folder.
  2. Open the repository on GitHub in the data/ folder.
  3. Click Add file → Upload files and drag the downloaded file in.
  4. Click Commit changes.
